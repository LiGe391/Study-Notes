# Study-Notes

我的个人学习笔记，主要面向中国高中理科知识，兼顾部分大学数学内容。

## 📖 内容概览

| 文档 | 学科 | 主要内容 |
| :--- | :--- | :--- |
| `Phy.md` | 物理 | 力学、电磁学模型与解题方法 |
| `Math.md` | 基础数学 | 高中数学核心知识 |
| `Math++.md` | 高等数学 | 微积分、微分方程、级数等 |
| `Chem·is·try.md` | 化学 | 结构化学、反应原理、电化学 |
| `Bio.md` | 生物 | 细胞、遗传、稳态与生态学 |
| `Cns.md` | 语文 | 语文各题型思路+知识积累 |
| `Vocab.md` | 英语 | 高考3500词汇+大学英语四级词汇 |

## 🏷️ 笔记特色

- **rct 标记**：`rct` = recite，标注需要熟记的核心结论、公式与易错点。
- **模型导向**：以物理、化学中的经典模型为线索组织知识。
- **个人简写**：生物等学科使用个人简写系统（如 `ezm` = 酶），提高记录效率。

## 🚀 使用建议

- 使用支持 LaTeX 的 Markdown 编辑器（如 Typora、Obsidian）以获得最佳阅读体验。
- 利用 GitHub 搜索功能快速定位特定知识点或模型。
